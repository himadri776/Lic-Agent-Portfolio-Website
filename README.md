# Prakriti Chakraborty — LIC Advisor Website

A lightweight responsive Next.js portfolio and lead-generation landing page for an LIC intermediary.

## Run locally
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Personalization before launch
- Replace the portrait placeholders in the hero and About section with Prakriti's actual photo.
- Replace gallery placeholders with authentic awards, event photos and achievement evidence.
- Add a real email address if email enquiry is desired.
- Verify current LIC policy features, plan availability and official plan links before publishing. This site intentionally does not present premium quotes or guaranteed benefit projections.
- Review the agent code and contact/address details.

## Stack
Next.js App Router, React, TypeScript, Lucide icons and plain CSS. No backend or analytics dependency. WhatsApp and telephone CTAs are functional.

## Design notes
Navy + sage + warm ivory palette, neumorphic cards/calculator controls, lightweight SVG/icon treatments, mobile navigation, contact CTA and responsive sections.
